Activity 2.3.3. Vertical Stretch and Compression.

How is the graph of a function affected if we multiply the formula by a constant? In other words, how is the graph of \(y=af(x)\) different from the graph of \(y=f(x)\) ?

(a)

Graph \(Y_1 = \abs{x}\) and \(Y_2 = 2\abs{x}\) in the same window.

Does the graph of \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(b)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) (Locate a specific \(x\)-value in the table and compare the \(Y_1\) and \(Y_2\) values for that input. How are they related?)

Try the same comparison for several other \(x\)-values.

(c)

Now change your definition of \(Y_2\) to \(Y_2 = \frac{1}{2}\abs{x}\text{.}\)

Does the graph of this new \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(d)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) How are they related?

(e)

Define \(Y_2 = a \abs{x}\) for various values of \(a\text{,}\) including \(a \gt 1\) and \(0 \lt a \lt 1\text{.}\) Compare the graph and Table values of \(Y_2\) with those of \(Y_1\text{.}\) Describe how the value of \(a\) affects the graph of \(Y_1\text{.}\)

(f)

Now change the basic function to the square root function, \(Y_1=\sqrt{x}\text{,}\) and repeat the previous task with \(Y_2=a \sqrt{x}\text{.}\) Do your answers to the previous task still hold for the new functions?

(g)

Now define \(Y_2 = -\abs{x}\text{.}\)

Does the graph of \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(h)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) How are they related?

(i)

Define \(Y_2 = a \abs{x}\) for various negative values of \(a\text{,}\) including \(a \lt -1\) and \(-1 \lt a \lt 0\text{.}\) Compare the graph and Table values of \(Y_2\) with those of \(Y_1\text{.}\) Describe how the value of \(a\) affects the graph of \(Y_1\) when \(a\) is negative.

(j)

Now change the basic function to the square root function, \(Y_1=\sqrt{x}\text{,}\) and repeat the previous task with \(Y_2=a \sqrt{x}\) for negative values of \(a\text{.}\) Do your answers to the previous task still hold for the new functions?
