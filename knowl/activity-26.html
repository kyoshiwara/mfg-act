Activity 2.3.2. Horizontal Shift.

How is the graph of a function affected if we add a constant to the independent variable? In other words, how is the graph of \(y=f(x+h)\) different from the graph of \(y=f(x)\text{?}\)

(a)

Graph \(Y_1 = \abs{x}\) and \(Y_2 = \abs{x-2}\) in the same window.

Does the graph of \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(b)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) (Locate a specific output value in the \(Y_1\) column and note its corresponding \(x\)-value. Now find the same output value in the \(Y_2\) column and note its \(x\)-value. How are the two \(x\)-values related?)

Try the same comparison for several other \(x\)-values.

(c)

Now change your definition of \(Y_2\) to \(Y_2 = \abs{x+4}\text{.}\)

Does the graph of this new \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(d)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) How are they related?

(e)

Define \(Y_2 = \abs{x+h}\) for various positive and negative values for \(h\) and compare the graph and Table values of \(Y_2\) with those of \(Y_1\text{.}\) Describe how the value of \(h\) alters the graph of \(Y_1\text{.}\)

(f)

Now change the basic function to the square root function, \(Y_1=\sqrt{x}\text{,}\) and repeat the previous task with \(Y_2=\sqrt{x+h}\text{.}\) Do your answers to the previous task still hold for the new functions?
