Activity 2.3.1. Vertical Shift.

How is the graph of a function affected if we add a constant to the formula? In other words, how is the graph of \(f(x)+k\) different from the graph of \(y=f(x)\) ?

(a)

Use technology to graph the absolute value function, \(Y_1 = \abs{x}\text{,}\) in a standard window, \([-10, 10] \times [-10, 10]\text{.}\) Create a table of values for \(y=\abs{x}\text{,}\) starting at \(x=-3\) with \(\Delta x = 1\text{.}\)

(b)

Graph \(Y_2 = \abs{x}-3\) in the same window with \(Y_1\text{.}\)

Does the graph of \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(c)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) (Locate a specific \(x\)-value in the table and compare the \(Y_1\) and \(Y_2\) values for that input. How are they related?)

Try the same comparison for several other \(x\)-values.

(d)

Now change your definition of \(Y_2\) to \(Y_2 = \abs{x}+3\text{.}\)

Does the graph of this new \(Y_2\) have the same shape as the graph of \(Y_1\text{?}\)

How is the graph of \(Y_2\) different from the graph of \(Y_1\text{?}\)

(e)

Use the Table to compare the function values for \(Y_2\) with the function values for \(Y_1\text{.}\) How are they related?

(f)

Define \(Y_2 = \abs{x}+k\) for various positive and negative values for \(k\) and compare the graph and Table values of \(Y_2\) with those of \(Y_1\text{.}\) Describe how the value of \(k\) alters the graph of \(Y_1\text{.}\)

(g)

Now change the basic function to the square root function, \(Y_1=\sqrt{x}\text{,}\) and repeat the previous task with \(Y_2=\sqrt{x}+k\text{.}\) Do your answers to the previous task still hold for the new functions?
